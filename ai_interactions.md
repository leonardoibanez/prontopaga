# Uso de herramientas de IA

Se utilizó OpenCode con el modelo Grok para completar el frontend pendiente del desafío (login, consulta de score, BFF con cookie HttpOnly, pruebas y documentación). El criterio de diseño, el contrato de backend y la arquitectura same-origin ya definidos en el repositorio se conservaron; la IA apoyó la implementación, las pruebas y el texto de entrega.
